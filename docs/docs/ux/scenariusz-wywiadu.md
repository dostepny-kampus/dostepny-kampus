# Scenariusz wywiadu z użytkownikami

| Element | Ustalenie |
| --- | --- |
| Cel | Sprawdzić hipotezy N1–N4 (Odwiedzający) i poznać kontekst użycia |
| Metody | Wywiad pogłębiony (półstrukturyzowany) + krótka obserwacja zadaniowa |
| Uczestnicy | Osoby 60+, min. 2 na członka zespołu (4–6 wywiadów) |
| Czas | ≈ 30 min na osobę + 10 min rezerwy (wolne tempo, zgoda pisemna) |
| Prowadzą | Członkowie zespołu: prowadzący i, jeśli to możliwe, notujący |
| Wynik | Arkusze notatek P1…P6 i tabela wniosków dla N1–N4 |
| Opcja | 1 wywiad z osobą zbierającą dane (N5–N9), sekcja 10 |

Hipotezy N1–N9 opisuje strona [Potrzeby i historyjki](../wymagania/potrzeby-i-historie.md). Wywiady to wymaganie etapu 2 kursu „Projektowanie doświadczeń użytkownika”. Wyniki zasilają persony i historyjki w etapie 3.

## 1. Dobór metod

| Metoda | Co daje | Ograniczenie | Gdzie w scenariuszu |
| --- | --- | --- | --- |
| Wywiad pogłębiony | doświadczenia, motywacje, słowa uczestnika | to deklaracje: „co mówią” | części 1–4 i 6 |
| Obserwacja zadaniowa z głośnym myśleniem | rzeczywiste zachowanie z własnym telefonem | krótka, w wyobrażonej sytuacji | część 5 |
| Ankieta — odrzucona | — | przy 4–6 osobach nie pozwala dopytać „dlaczego” | — |
| Grupa fokusowa — odrzucona | — | trudno mówić przy innych o własnych ograniczeniach | — |

Szukamy potrzeb, a nie oceny gotowego projektu, dlatego podstawą jest wywiad indywidualny. NN/g opisuje wywiad jako metodę odkrywania doświadczeń i problemów użytkowników. Ta sama grupa ostrzega, że wywiad pokazuje tylko to, co ludzie deklarują. Dlatego dodajemy krótką obserwację: uczestnik pokazuje na swoim telefonie, jak przygotowuje wizytę.

## 2. Rekrutacja

| Kryterium | Wymóg |
| --- | --- |
| Wiek | 60 lat lub więcej |
| Związek z kampusem | odwiedza kampus PWr lub mógłby go odwiedzić (wykład otwarty, wydarzenie, sprawa na uczelni, wizyta u bliskich) |
| Przykład grupy | słuchacze Politechniki Trzeciego Wieku — programu PWr dla osób 60+ (ok. 200 słuchaczy od października 2025) |
| Telefon | korzysta z telefonu komórkowego; min. połowa uczestników używa smartfona |
| Mobilność (opcjonalnie) | min. 1 osoba w całej próbie porusza się z trudem (laska, balkonik, wózek) albo słabo widzi — według tego, co sama mówi |
| Wykluczenie | studenci i pracownicy PWr, osoby znające projekt, członkowie zespołu; słuchacze Politechniki Trzeciego Wieku nie są wykluczeni |

- Każdy członek zespołu rekrutuje osobiście 2 osoby z własnego otoczenia, np. przez znajomych, klub seniora albo uniwersytet trzeciego wieku.
- Bliska rodzina członka zespołu tylko wtedy, gdy brak innych chętnych. Zaznacz to w arkuszu (ryzyko uprzejmych odpowiedzi).
- Staraj się o różnorodność: różny wiek (60–69, 70–79, 80+), płeć i obycie z telefonem.

## 3. Przygotowanie

- Przeprowadź 1 wywiad próbny z kimkolwiek z otoczenia. Popraw pytania, które budzą wątpliwości.
- Wydrukuj arkusz notatek. Dla uczestnika miej wydruk zgody dużą czcionką (min. 16 pt).
- Wybierz ciche miejsce z dobrym światłem. Uczestnik ma przy sobie własny telefon i okulary, jeśli ich używa.
- Nie pokazuj szkiców aplikacji ani nazwy projektu. Pytamy o potrzeby, nie o nasz pomysł.

## 4. Zgoda uczestnika (do odczytania)

Prowadzący czyta tekst powoli i daje wydruk do ręki.

> Dzień dobry. Nazywam się [imię] i studiuję na Politechnice Wrocławskiej. W projekcie na zajęciach badamy, jak osoby starsze planują wizyty w budynkach uczelni.
>
> Rozmowa potrwa około 30 minut. Nie ma dobrych ani złych odpowiedzi. Nie sprawdzamy Pana/Pani, tylko nasze pomysły.
>
> Udział jest dobrowolny. Może Pan/Pani nie odpowiadać na pytanie albo przerwać w każdej chwili, bez podawania powodu. Może Pan/Pani także wycofać zgodę po rozmowie.
>
> Nie zapisujemy imienia, nazwiska ani adresu. W notatkach będzie Pan/Pani oznaczony/oznaczona jako „uczestnik” z numerem. Cytaty w raporcie nie pozwolą Pana/Pani rozpoznać.
>
> Nie pytamy o choroby ani diagnozy. Notatki służą tylko do tego projektu i usuniemy je po zakończeniu semestru.
>
> Kontakt: [imię i nazwisko], [uczelniany adres e-mail].
>
> Czy zgadza się Pan/Pani na rozmowę? Czy zgadza się Pan/Pani na nagranie dźwięku, które usuniemy po spisaniu notatek?

Odpowiedzi zapisz w nagłówku arkusza. Brak zgody na nagranie nie wyklucza rozmowy. Podstawa prawna to zgoda uczestnika (RODO, artykuł 6 ustęp 1 litera a oraz artykuł 7).

| 4.2 | Proszę opowiedzieć o sytuacji, gdy samo wejście do budynku sprawiło kłopot Panu/Pani albo komuś, z kim Pan/Pani był(a). | Co Pan/Pani wtedy zrobił(a)? | N1 |

| 4.5 | Proszę przypomnieć sobie ostatnią przeszkodę w budynku, np. zepsutą windę. Co Pan/Pani wtedy zrobił(a)? | Co było dalej? | N3 |
| 4.6 | Jak chciał(a)by Pan/Pani przekazać taką informację, jeśli w ogóle? | Ile czasu mógłby/mogłaby Pan/Pani na to poświęcić? | N3 |
| 4.7 | Które aplikacje albo strony są dla Pana/Pani najwygodniejsze? Co je takimi czyni? | Proszę pokazać jedną z nich. | N4 |

Nie wymieniaj daty sprawdzenia ani zdjęć w pytaniach 4.3–4.4. Jeśli uczestnik sam o nich powie, zapisz to jako mocny dowód dla N2.

### Część 5. Zadanie „wykład w C-13”

Prowadzący czyta:

> Za tydzień idzie Pan/Pani na otwarty wykład w budynku C-13 Politechniki Wrocławskiej. Nigdy Pan/Pani tam nie był(a). Proszę pokazać na swoim telefonie, jak Pan/Pani się do tego przygotuje. Proszę przy tym mówić na głos, o czym Pan/Pani myśli.

- Nie pomagaj i nie podpowiadaj. Gdy uczestnik milknie, powiedz tylko: „O czym Pan/Pani teraz myśli?”.
- Gdy uczestnik utknie na dłużej niż 1 minutę, zapytaj: „Co by Pan/Pani zrobił(a) teraz?”.
- Uczestnik bez smartfona opowiada, co zrobiłby krok po kroku.
- Jeśli uczestnik zna już C-13, podaj inny budynek, w którym nie był, np. D-1.

| Co obserwujesz | Weryfikuje |
| --- | --- |
| Od czego zaczyna: mapa, strona PWr, wyszukiwarka, telefon do kogoś | N1 |
| Jakich informacji szuka: wejście, winda, toaleta, przystanek, parking | N1 |
| Po czym ocenia, czy znaleziona informacja jest wiarygodna | N2 |
| Gdzie się waha, myli albo rezygnuje | N4 |
| Powiększanie tekstu, mrużenie oczu, chybione dotknięcia | N4 |

| Nr | Pytanie po zadaniu | Weryfikuje |
| --- | --- | --- |
| 5.1 | Jak pewnie czuje się Pan/Pani teraz przed takim wyjściem? Od czego to zależy? | N1, N2 |
| 5.2 | Co by Pan/Pani zrobił(a), gdyby na miejscu wejście było zamknięte? | N1, N3 |

| Nr | Pytanie | Weryfikuje |

| 6.2 | Czy jest coś ważnego, o co nie zapytałem/zapytałam? | N1–N4, nowe potrzeby |

Podziękuj. Kontakt do ponownej rozmowy zapisz w osobnym miejscu, nigdy w arkuszu.

### Zasady prowadzenia

- Jedno pytanie naraz. Mów wolno i wyraźnie, patrz na rozmówcę.
- Po odpowiedzi odczekaj kilka sekund. Często pada wtedy najważniejsze zdanie.
- Dopytuj neutralnie: „Proszę powiedzieć więcej”, „Dlaczego?”, „Co było dalej?”.
- Nie oceniaj odpowiedzi i nie tłumacz się z pomysłu.
- Pytaj o konkretne, minione sytuacje, a nie o opinie „na ogół”.

## 8. Wnioski

1. W ciągu 24 godzin po wywiadzie uzupełnij arkusz i usuń nagranie.
2. Przepisz cytaty i obserwacje na karteczki, po jednej myśli na karteczkę.
3. Wspólnie pogrupujcie karteczki w tematy (diagram pokrewieństwa).
4. Każdy temat przypiszcie do N albo oznaczcie jako nową potrzebę.
5. Wypełnijcie tabelę poniżej według reguł decyzji.

| Status | Reguła decyzji |
| --- | --- |
| Potwierdzona | połowa uczestników lub więcej mówi o niej albo ją pokazuje bez podpowiedzi |
| Zmieniona | potrzeba istnieje, ale ma inną treść, inny priorytet albo inną grupę |
| Odrzucona | nikt jej nie potwierdza albo większość jej przeczy |
| Nowa | temat bez N, obecny u min. 2 uczestników; dostaje kolejny numer N10… |

| N | Status | Dowód (P…, nr pytania) | Nowe brzmienie, jeśli zmieniona | Skutek dla funkcji |
| --- | --- | --- | --- | --- |
| N1 | | | | |
| N2 | | | | |
| N3 | | | | |
| N4 | | | | |
| N5–N9 | (opcjonalnie, sekcja 10) | | | |
| N10… | nowa | | | |

Zmienioną albo odrzuconą potrzebę zespół zgłasza do poprawy dokumentów przed implementacją. Funkcja odrzuconej potrzeby idzie do ponownej oceny.

## 10. Wywiad z osobą zbierającą dane (opcjonalny, N5–N9)

| Element | Ustalenie |
