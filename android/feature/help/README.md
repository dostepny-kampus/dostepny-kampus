# :feature:help

## Zadanie

Pomoc: ekran z krokami obsługi i jego pokazanie przy pierwszym uruchomieniu.

## API

Trasa pomocy w pakiecie `navigation`.

## Zależności

- `:core:data`
- `:core:designsystem`
- `:core:model`

## Czego moduł nie robi

Nie zawiera instrukcji innych ekranów w ich kodzie i nie zapisuje niczego poza znacznikiem pierwszego uruchomienia.

## Kiedy dodawać tutaj

Treść i ekran pomocy. Podpowiedź przy jednym ekranie zostaje w module tego ekranu.
