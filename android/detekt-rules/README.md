# :detekt-rules

## Zadanie

Własne reguły detekt projektu: opisy KDoc tylko z kontraktem, bez numerów historii, wymagania w jednej linii, bez komentarzy liniowych.

## API

`DostepnyKampusRuleSetProvider` z regułami dla konfiguracji detekt.

## Zależności

Brak zależności od innych modułów projektu.

## Czego moduł nie robi

Nie zawiera kodu aplikacji i nie trafia do APK.

## Kiedy dodawać tutaj

Reguła, której nie ma w detekt ani ktlint, a która pilnuje standardu projektu. Najpierw sprawdź gotowe reguły.
